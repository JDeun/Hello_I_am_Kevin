## 자세히

위 프로젝트 중 셋을, 왜 그렇게 만들었는지와 함께.

### SchemaRouter — 논문과 라이브러리

SchemaRouter는 RAG·에이전트 앱과 그것이 호출하는 도구 사이에 놓입니다. OpenAPI·MCP·OPTIMADE·Python·플러그인 도구를 하나의 타입 있는 카탈로그로 묶고, 요청에 맞는 실행 경로를 좁혀 고른 뒤, **실행 전과 후 양쪽에서** 계약을 검사합니다. 일반 에이전트 프레임워크도, LLM 프로바이더 계층도, RAG 생성기도 **아닙니다.**

[논문](https://arxiv.org/abs/2608.21375)은 의미 유사도만이 아니라 스키마도 라우팅 문제의 일부라고 주장합니다. 그 주장을 그대로 설치해 쓸 수 있게 만든 것이 이 라이브러리입니다.

- 어댑터 5종 — MCP, OpenAPI, OPTIMADE, Python, 플러그인
- 생태계 통합 8종 — LangChain, LangGraph, LlamaIndex, Ollama, OpenTelemetry 등
- 어댑터와 **의사결정 백엔드가 둘 다** 엔트리포인트 플러그인이라, 새 도구 소스나 새 라우팅 전략을 코어 수정 없이 붙일 수 있습니다
- 승인 콜백, 실행 예산, 증거 요구사항, 바인딩 드리프트 감지
- `py.typed`, 국영문 문서 사이트

### Helm

**Helm**은 계속 돌아가는 에이전트를 운영하는 계층입니다. 숨은 런타임 동작을 들여다보고 지정할 수 있는 것으로 바꿉니다 — 실행 프로파일, 컨텍스트 하이드레이션, 매니페스트 기반 스킬 정책, 감사 기록, 운영 경계.

### LangTextFlow · GrowWise · AudioScoreTool — 반복되는 한 가지 문제

서로 다른 제품이지만 밑바닥 구조가 같습니다. **불완전한 모델 출력 → 검증된 상태 → 사람의 교정 → 최종 산출물.**

확신이 서기 전에 확정해야 하는 자막. 생성된 요약이 조용히 사실의 출처로 올라서면 안 되는 학습 기록. 사용자가 입력하는 대신 고치는 악보 초안.

셋 다 로컬 우선이고 FastAPI 기반이며 데스크톱으로 패키징됩니다.

## 일하는 방식

아래는 모두 위 저장소에서 직접 확인할 수 있습니다.

- **감추지 않기** — Helm은 숨은 런타임 동작을 실행 프로파일·매니페스트 기반 스킬 정책·감사 기록으로 바꿉니다. 돌려보기 전에 읽을 수 있습니다.
- **권한에는 한계를** — SchemaRouter에서 도구 호출은 승인 콜백과 실행 예산을 들고 다니고, 계약은 실행 전후 양쪽에서 검사됩니다.
- **원본이 요약보다 먼저** — GrowWise는 Markdown을 사실의 출처로 두고 SQLite를 거기서 다시 만듭니다. AI가 만든 요약이 나머지 전부가 믿는 근거로 올라서지 않습니다.
- **안 끝난 건 안 끝났다고** — LangTextFlow와 AudioScoreTool은 각자의 첫 화면에 미출시라고 적어두었습니다. 서명되지 않은 CI 산출물은 배포된 제품이 아니고, 그걸 제품이라 부르는 대가가 기다리는 것보다 큽니다.
- **실패에서 나온 연구** — 하네스 논문 두 편은 제가 운영하던 시스템에서 어설픈 래퍼가 계속 맨 모델에 지는 것을 보고 썼습니다.
